## Mapa de Módulos

### 1. Integração Brownfield

Adicionando React Native a um aplicativo nativo já existente. Aplicativos host, configuração da bridge, roteamento entre telas nativas e RN.

---

### 2. TurboModules

Criando módulos nativos de alta performance com a Nova Arquitetura. Bindings JSI, geração de código, interfaces tipadas.

---

### 3. Fabric e JSI em Profundidade

Internos do novo pipeline de renderização. Camada C++, chamadas síncronas, shadow tree, funcionalidades concorrentes.

---

### 4. Performance, Bundle e CI/CD

Configuração do bundler Metro, Hermes, profiling, tempo de inicialização, pipelines de release e entrega automatizada.

---

### 5. Animações

Thread JS vs thread UI, API Animated na Nova Arquitetura, worklets e shared values do Reanimated 3, animações de layout orientadas a gestos e profiling de performance de animações.

---

### 6. Manutenção: Atualizações de Versão do React Native

Estratégias para atualizar versões do RN com segurança. Gerenciamento de dependências, breaking changes, tooling.
